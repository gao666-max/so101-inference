# SO101 ACT 推理控制项目 —— 改造计划

## 为什么要改造成项目

你现在有一堆单文件脚本（inference.py, inference_control.py...），每改一个参数就要改代码。
面试官不会看"一个脚本"，但会看"一个有 README、有配置、有错误处理的项目"。

## 项目结构

```
so101_act_inference/                    ← 你的 GitHub 仓库
├── README.md                           ← 项目说明 + 环境要求 + 使用方式
├── requirements.txt                    ← pip 依赖
├── config.yaml                         ← 配置（串口、摄像头编号、SCALE、路径）
├── run_inference.py                    ← 入口：python run_inference.py
│
└── so101_inference/                    ← 核心代码包
    ├── __init__.py
    ├── config.py                       ← 读取 config.yaml
    ├── model_loader.py                 ← 加载 ACT 模型 + 归一化参数 + homing_offset
    ├── servo_control.py                ← 串口连接、舵机读写、使能/去使能、安全检查
    ├── camera_pipeline.py              ← 摄像头采集、图像预处理（ImageNet标准化）
    ├── inference_engine.py             ← 推理主循环（模型输入→输出→值域转换→串口写入）
    └── safety.py                       ← 安全保护（MAX_DELTA钳位、位置限幅、急停）
```

## 每个文件的职责（你写代码时要问自己的问题）

### model_loader.py
- 模型从哪个路径加载？如果路径不存在怎么办？
- 归一化参数 mean/std 从哪个文件读？键名是什么？
- homing_offset 从哪里来？（标定文件 / 写死在 config.yaml？）
- 如果模型文件损坏（比如下载中断），怎么检测？（checksum？文件大小？）

### servo_control.py
- 串口路径是硬编码还是从 config 读？
- 如果串口被占用，怎么重试？重试几次？间隔多久？
- read_raw() 返回值是什么类型？（int 还是 List[int]？）
- 写舵机前有没有检查 value 在 0-4095 范围内？
- 每步最大移动量 MAX_DELTA 是不是可配置的？

### camera_pipeline.py
- 摄像头编号是硬编码还是从 config 读？
- 如果摄像头被拔了，怎么处理？返回 None？重试？抛异常？
- 图像预处理：BGR→RGB→resize→归一化，每一步的输入输出形状是什么？
- 有没有预热帧？

### inference_engine.py
- 推理循环的帧率是多少？由什么决定？（摄像头 30fps / 模型推理耗时 / waitKey 延迟）
- 平滑窗口大小是多少？为什么是 5 帧？
- SCALE 放大倍数的合理范围是多少？
- 按 q 退出和 Ctrl+C 退出有什么区别？哪个更安全？

### config.yaml（示例）
```yaml
model:
  path: "pretrained_model/"
  weights: "model.safetensors"

servo:
  port: "/dev/ttyACM0"
  baudrate: 1000000

camera:
  index: 2
  width: 640
  height: 480
  fps: 30

inference:
  scale: 1.0
  max_delta: 50
  smooth_window: 5
  clamp_range: [0, 4095]

homing:
  shoulder_pan: -1033
  shoulder_lift: 836
  elbow_flex: 846
  wrist_flex: 1065
  wrist_roll: -1685
  gripper: 2036
```

## 改造步骤（你写，我在旁边讲原理）

1. 把 inference_control.py 里的 read_raw / write_joints / enable_torque 抽到 servo_control.py
2. 把模型加载和归一化参数抽到 model_loader.py
3. 把摄像头和图像预处理抽到 camera_pipeline.py
4. 把推理循环抽到 inference_engine.py
5. 把硬编码的路径 / 端口 / 缩放因子全部移到 config.yaml
6. 写 README.md（有 5 个要素就够了：是什么 / 环境 / 安装 / 怎么用 / 踩坑记录）
7. 推到 GitHub
